# Core Revision

This folder contains the **high-value technical concepts and interview questions** that I need to revise regularly.

The goal is not to memorize everything from the knowledge base.  
The goal is to maintain strong recall of the concepts that are most relevant to my target Backend/PHP/Laravel roles.

## 🎯 Purpose

- Build strong fundamentals
- Improve active recall
- Identify weak technical areas
- Reduce unnecessary revision
- Keep a small and manageable revision list

## 📚 Topics

- PHP
- Laravel
- MySQL
- JavaScript
- REST API
- Git & Linux

## 🔄 Revision Strategy

Questions are classified into four levels:

| Level | Meaning |
|---|---|
| 🔴 L0 | Don't know / cannot answer |
| 🟡 L1 | Understand the concept but cannot explain clearly |
| 🟢 L2 | Can explain with minor difficulty |
| 🔵 L3 | Interview-ready |

### Revision Cycle

A question should normally be reviewed:

**Day 1 → Day 3 → Day 7 → Day 21**

If I can answer it confidently multiple times, it can be moved out of active revision.

## 🧠 Active Recall Rule

Do not read the answer first.

For every question:

1. Read the question
2. Answer it without looking at the notes
3. Compare with the expected answer
4. Identify missing points
5. Update the mastery level

## 🚫 Important Rule

This folder should remain **small**.

Do not add every question from the main knowledge base.

Only add questions that are:

- Frequently asked
- Fundamental
- Relevant to target jobs
- Difficult to remember
- Previously answered incorrectly
