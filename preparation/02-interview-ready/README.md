# Interview Ready

This folder contains the **smallest and most important set of questions** that I should be able to answer confidently before attending a technical interview.

This is NOT a complete question bank.

It represents my **interview-ready knowledge**.

## 🎯 Purpose

- Prepare efficiently before interviews
- Focus on high-frequency questions
- Build confidence in core technologies
- Avoid revising hundreds of questions unnecessarily

## 📌 Priority

The content should primarily focus on:

### Primary

- PHP
- Laravel
- MySQL

### Secondary

- JavaScript
- REST APIs
- Git
- Linux

### Advanced

- System Design
- Redis
- Docker
- AWS
- Queues
- Testing

## 🧩 What Belongs Here?

A question belongs here when:

- It is commonly asked in interviews
- It tests an important concept
- It is relevant to my experience
- I have encountered it multiple times
- I can explain it using a practical example

## 🎤 Answer Standard

For each question, I should be able to:

1. Give a direct answer
2. Explain the concept
3. Give a practical example
4. Explain when/why it is used
5. Discuss common problems or trade-offs when applicable

## ⏱️ Interview Simulation

Questions should eventually be answerable without notes.

Target:

**30–90 seconds for normal questions**

**2–3 minutes for advanced/scenario questions**

## 🚫 Don't Do This

Do not copy the entire interview question bank here.

Do not memorize scripted answers.

Do not add questions simply because they are interesting.

The goal is:

> **Understand → Recall → Explain → Apply**
